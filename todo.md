## 🤰 МОДУЛЬ 1: Рахування переймів (Contraction Timer)

### 🎯 Мета
Надати майбутній мамі та партнеру зручний інструмент для фіксації переймів, автоматичного розрахунку інтервалів і тривалості, а також своєчасного визначення моменту, коли необхідно вирушати до пологового будинку (за медичним правилом **5-1-1**).

### 📐 Схема даних (`src/db.ts`)
```typescript
export interface Contraction {
  id?: number;
  startTime: number;       // Timestamp початку перейми (ms)
  endTime?: number;        // Timestamp завершення перейми (ms)
  duration: number;        // Тривалість у секундах
  interval?: number;       // Інтервал (секунди від початку попередньої перейми)
  restDuration?: number;   // Період спокою (секунди від кінця попередньої перейми)
  intensity?: 'mild' | 'moderate' | 'strong'; // Інтенсивність: легка, середня, сильна
  notes?: string;          // Нотатки (напр., "відійшли води", "біль у спині")
  isFalseAlarm?: boolean;  // Позначка тренувальних переймів (Брекстона-Гікса)
}
```

### 🧠 Медична логіка та алгоритми
- **Розрахунок інтервалу:**
  - *Медичний інтервал* = `поточна.startTime - попередня.startTime` (час між початками двох сусідніх переймів).
  - *Період відпочинку* = `поточна.startTime - попередня.endTime`.
- **Правило 5-1-1 (Пора їхати в пологовий):**
  - **5** хвилин: інтервал між переймами 5 хвилин або менше.
  - **1** хвилина: тривалість кожної перейми приблизно 60 секунд (від 45 до 90 сек).
  - **1** година: така регулярність утримується щонайменше 60 хвилин поспіль.
- **Підтримка правила 4-1-1:** опція в налаштуваннях (актуально для повторних пологів).
- **Статусні індикатори:**
  - 🟢 *Спокій / Рання фаза:* нерегулярні перейми (відпочивайте, пийте воду).
  - 🟡 *Активна підготовка:* перейми стають регулярнішими (перевірте зібрані сумки).
  - 🔴 *Час вирушати до пологового:* спрацювало правило 5-1-1 (кнопка виклику лікаря / швидкої).

### 🛠️ Технічні виклики та рішення
- **Фоновий режим в iOS Safari / PWA:** `setInterval` засинає при згортанні додатка чи блокуванні екрана.
  - *Рішення:* Зберігати точний `startTime = Date.now()` у `localStorage`/`Dexie`. При поверненні розраховувати тривалість як `Math.floor((Date.now() - startTime) / 1000)`.

## 🎒 МОДУЛЬ 2: Чеклист речей по сумках у пологовий (Hospital Bag Checklist)

### 🎯 Мета
Структурувати збори до пологового будинку за перевіреними категоріями (сумками), надати стандартний український перелік речей із можливістю редагування, відстеження прогресу та пошуку потрібного предмету.

### 📐 Схема даних (`src/db.ts`)
```typescript
export interface HospitalBag {
  id?: number;
  name: string;        // Назва: 'Родзал', 'Післяпологова (Мама)', 'Для малюка', 'Виписка', 'Партнер'
  code: string;        // Унікальний ключ: 'labor', 'mom', 'baby', 'discharge', 'partner'
  icon: string;        // Назва іконки Lucide ('Baby', 'HeartHandshake', 'Sparkles', тощо)
  color: string;       // Tailwind-колір для бейджа/прогрес-бару
  order: number;       // Порядок відображення
}

export interface BagItem {
  id?: number;
  bagId: number;       // ID відповідної сумки
  name: string;        // Назва речі (напр., "Пелюшки одноразові 60х90")
  quantity: number;    // Кількість
  unit?: string;       // Одиниці ('шт', 'уп')
  isPacked: boolean;   // Чи зібрано в сумку
  notes?: string;      // Корисна підказка (напр., "покласти зверху")
  shoppingUrl?: string;// Посилання на покупку (зв'язок з Модулем 3)
  order: number;
}
```

### 📦 Стандартні прозорі сумки та наповнення за замовчуванням (Presets L / M / S)

Базова структура відповідає стандарту прозорих сумок у пологовий (M — родзал, L — післяпологова мами, S — дитяча):

1. **Середня сумка (M) — Сумка на пологи (в родзал)**
   - **Документи** (паспорт, ідентифікаційний код, обмінна карта з УЗД, страховий поліс/договір) — *зверху або в окремій кишені*.
   - **Пляшка води** (1.5 л, бажано зі спортивним дозатором).
   - **Одяг для пологів:** нічна сорочка №1, шкарпетки (1 пара), гумові миючі капці.
   - **Зволожуючий бальзам для губ** (гігієнічна помада).
   - **Гігієна в родзал:** паперові рушники (1 рулон) та 5–10 одноразових пелюшок 60×90.
   - **Речі для дитини на перші хвилини (в окремому пакеті/зверху):**
     - Перший комплект одягу (боді, чоловічок, шапочка, носочки/царапки).
     - Дитячий пледик.
     - 2 тканинні пелюшки (1 ситцева + 1 байкова).
     - 2–3 підгузки (розмір 0 або 1).
     - 1 пачка дитячих вологих серветок.

2. **Велика сумка (L) — Післяпологова для мами**
   - **Одяг та взуття для палати:** зручний халат і друга нічна сорочка (для годування), звичайні м'які капці, шкарпетки (2-3 пари).
   - **Рушники:** великий рушник для душу + рушник для рук/обличчя.
   - **Пелюшки одноразові:** 60×90 (основний запас із пачки, 10–15 шт).
   - **Післяпологова гігієна:**
     - Післяпологові/урологічні прокладки максимального поглинання (20 шт).
     - Одноразові післяпологові трусики-сіточка (4-5 шт).
     - Бюстгальтери для годування (1-2 шт) та одноразові лактаційні прокладки для грудей.
     - Крем для сосків (100% чистий ланолін, напр. Purelan).
   - **Засоби особистої гігієни:** зубна паста, зубна щітка, шампунь, гель для душу, гребінець, вологий туалетний папір.
   - **Побут та посуд:** особистий посуд (чашка, ложка, тарілка), залишок рулону паперових рушників, зарядні пристрої / подовжувач.

3. **Маленька сумка (S) — Післяпологова для малюка**
   - **Змінний одяг на 3–4 доби:** комплекти чоловічків, боді, повзунків, шапочок та шкарпеток (випрані дитячим засобом і попрасовані).
   - **Тканинні пелюшки:** по 4 ситцеві та 4 байкові пелюшки.
   - **Підгузки:** основний запас підгузків для немовлят (пачка 1-го розміру на 24–40 шт).
   - **Серветки:** залишок або нова велика пачка дитячих вологих серветок (99% води).
   - **Дитяча аптечка та догляд:** електронний термометр із м'яким наконечником, стерильна вата, ватні диски, дитячі ножиці з закругленими кінчиками, захисний крем під підгузок.

*(Додатково користувач може створити або підключити опціональні сумки: «На виписку» та «Для партнера на пологи»).*

## 🛍️ МОДУЛЬ 3: Список покупок із завантаженням фото, опису та цін (Shopping Wishlist & Link Preview)

### 🎯 Мета
Створити єдиний вішліст покупок для малюка та мами. Користувач вставляє посилання на товар із будь-якого українського чи міжнародного інтернет-магазину (Rozetka, MA, Pampik, Chicco, Prom, Amazon, iHerb тощо), а додаток автоматично парсить посилання та відображає картку товару з зображенням, назвою, описом та ціною.

### 📐 Схема даних (`src/db.ts`)
```typescript
export interface ShoppingItem {
  id?: number;
  url: string;             // Посилання на товар
  domain: string;          // Домен магазину (напр., 'rozetka.com.ua', 'ma.com.ua')
  title: string;           // Назва товару
  description?: string;    // Короткий опис
  imageUrl?: string;       // URL головного зображення товару
  price?: number;          // Числове значення ціни
  currency: string;        // Валюта ('UAH', 'USD', 'EUR')
  isBought: boolean;       // Статус: придбано чи заплановано
  priority: 'high' | 'medium' | 'low'; // Пріоритет покупки
  category?: string;       // Категорія ('Малюк', 'Мама', 'Коляски/Меблі', 'Гігієна')
  linkedBagItemId?: number;// Зв'язок із пунктом у сумці для пологового (опціонально)
  notes?: string;          // Особисті нотатки (колір, розмір, промокод)
  createdAt: number;       // Дата додавання
}
```

### 🌐 Технічне вирішення проблеми CORS для парсингу посилань
У клієнтському браузері (PWA) прямий запит `fetch(url)` блокується політикою **CORS (Cross-Origin Resource Sharing)**.

#### Архітектурна багаторівнева стратегія:
1. **Рівень 1: Спеціалізований сервіс прев'ю посилань (Рекомендовано):**
   - Використання публічного endpoint `https://api.microlink.io?url={encodeURIComponent(url)}`.
   - Повертає готовий структурований JSON: `data.title`, `data.description`, `data.image.url`, `data.price`, `data.publisher`.
2. **Рівень 2: Відкриті CORS-проксі з власним парсингом HTML (Fallback):**
   - Використання `https://api.allorigins.win/get?url=...` або `https://corsproxy.io/?url=...`.
   - Отримання HTML-розмітки та парсинг через `DOMParser`:
     - **Зображення:** `meta[property="og:image"]`, `meta[name="twitter:image"]`, `link[rel="image_src"]`.
     - **Назва:** `meta[property="og:title"]`, `meta[name="twitter:title"]`, `<title>`.
     - **Опис:** `meta[property="og:description"]`, `meta[name="description"]`.
     - **Ціна:** `meta[property="product:price:amount"]`, `meta[property="og:price:amount"]`, пошук блоків `<script type="application/ld+json">` із сутністю `Product` або `Offer` (`offers.price`).
3. **Рівень 3: Гнучкий ручний режим (Manual Fallback):**
   - Якщо сайт захищений антибот-системою (Cloudflare Bot Fight Mode / Incapsula) або користувач офлайн:
   - Додаток пропонує зручну форму швидкого заповнення або редагування (вставити назву, ціну в грн, додати картинку або вибрати шаблонну іконку).

## 📱 МОДУЛЬ 4: Оновлення навігації та загального інтерфейсу (App Shell & Navigation)

### 🎯 Мета
Органічно поєднати всі модулі в єдиному зручному додатку, зберігаючи простоту та швидкість доступу в стресовий момент (наприклад, під час початку пологів).

### 🧭 Структура навігації
Нижній TabBar переформатовується на ключові робочі розділи:
1. 👣 **Поштовхи** (`Heart` / `Activity`) — головний лічильник рухів плода, історія сесій та статистика.
2. ⏱️ **Перейми** (`Timer` / `Flame`) — таймер переймів, аналіз правила 5-1-1, кнопка екстреного виклику.
3. 👜 **Сумки** (`ShoppingBag` / `Luggage`) — чеклист зборів у пологовий будинок по категоріях.
